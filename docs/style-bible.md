# Библия стиля: «Ертөстік» — қазақша мультфильм для всех возрастов (формат по образцу @aighaq)

## Образец (@aighaq «АЙҒАҚ», анализ 2026-11-27)
- Старт 2026-10-19 → за ~5,5 нед: 33 видео + 7 shorts, 488K просмотров, 1,9K подп. Выход 5–6 видео/нед.
- Длина: медиана 10:42 (5–23 мин). Топ: «1941 жылы майданға аттансаң…| POV» 178K; «Астанада зомби…» 57K; «Смартфонмен 1000 жыл бұрынғы Отырарға…» 56K.
- Что выстреливает: «СЕН» в центре (2-е лицо, POV), «а что если?», знакомое место/эпоха Казахстана, ставка выживания.
## Формула названия
`[Ситуация с СЕН / Если…] + [место/эпоха] + [вопрос-ставка]?` 6–12 слов, заканчивается «?», иногда `| POV`. Цифра или контраст (10→10 000, 99 адам) поднимает CTR.
## Формула превью
Слева/сверху 2–3 слова КАПСОМ (жёлтые с толстой чёрной обводкой, «?!»); справа/по центру — персонаж с испуганным лицом крупно + угроза/диковина на фоне. Яркий фон, высокая насыщенность. Вариант «эпик»: сепия-гравюра + 2–3 слова с красным подчёркиванием.
## Формула сценария
- 0:00–0:30 холодное открытие: короткие рубленые фразы «Қалтаңда… Бірақ… Саған бір апта шыдау керек.» → правила игры → «Ең қиын сынақ — …» 
- 0:30–1:00 условия эксперимента («Шарт қарапайым…»), дисклеймер «бұл ойша тәжірибе».
- Тело: 6–8 глав-этапов (1-күн, 2-күн… / шаг за шагом), каждая: проблема → наивная попытка героя → почему не работает → решение/помощник.
- Юмор: бытовые казахские детали (апаның шайы, қазы в холодильнике, ауыл) — на последнем слове.
- Финал: чек-лист «Біріншіден… Сегізіншіден…» → вопрос в коммент «Ал сен не істер едің? Пікірге жаз!» → «лучший ответ — в следующем видео» → короткая шутка-закрытие.
## Монтаж
1 фраза = 1 кадр (~2–3 с), карточки глав («1-КҮН: СУ»), плашки, счётчики, медленный наезд камеры, тряска на ударах, музыка под всем.
## Звук
Один ИИ-голос, спокойно-драматичный, ~110–120 слов/мин (каз. слова длинные), фоновая музыка постоянно.

## НАШ канал (копируем формат, не бренд)
- Тема: батыр-ертегі «Ер Төстік» (фольклор, общественное достояние) + другие казахские сказки. Аудитория — ВСЕ ВОЗРАСТЫ (основа 14–45, семьи смотрят вместе). Формат как у Pixar/«Шрека»: дети смотрят картинку, взрослые ловят второй слой.
- Приём «СЕН»: «Сен Ертөстіктің орнында болсаң?», «Жалмауыз кемпірден қалай құтыласың?».
- Палитра своя: дала-охра #E8B04B, закат #F26B3A, ночь-индиго #2B2D6E, киіз-қызыл #C0392B, бирюза неба #4FC3D9, крем #FFF4DC. Обводка тёмно-индиго #1E1B3A, 2 прохода.
- Персонажи-марионетки: капсульные руки/ноги, большая голова (дети 1:2.5, взрослые 1:4), круглые глаза-точки с бликом, моргание по хэшу имени. Ертөстік — ҚАЗАҚИ орнамент на шапан, без копий дизайна из мультфильма «Казахфильм».
- Фирменное: заставка-ою (орнамент раскрывается), карточки глав в рамке ою, счётчик «сынақ 1/7», рассказчик-мультяшный дедушка-ертегіші «Ата» (вместо мальчика в худи).
- Превью: белый/кремовый текст 1–3 слова, толстая индиго-обводка + оранжевый акцент; герой крупно справа, сказочная угроза слева.
- Статус YouTube: «НЕ для детей». YouTube решает по содержанию (не по аккаунту зрителя) и может переклассифицировать, поэтому контент ДЕЙСТВИТЕЛЬНО должен быть для всех:
  - подача «СЕН» от лица взрослого/подростка: «Ертөстіктің орнында болсаң, аман қалар ма едің?», логика выживания, разбор «почему герой так поступил»;
  - второй слой для взрослых: смысл мифа, тюркская мифология, параллели с современностью (ипотека Ерназара, «тойға шақыру» Жалмауыза), ирония;
  - НЕ использовать детские маркеры: колыбельные/детские песенки, «балақай/балалар, сәлем!», обучение счёту/цветам, игрушки, слово «балаларға» в названии/тегах/описании;
  - в метаданных: «қазақша анимация», «ертегі», «мифология», «батырлар жыры», «отбасымен көріңіз»;
  - сюжет без жести (смотрят и дети): страшно-смешно, без крови.
- Призыв: «Ал сен не істер едің? Пікірге жаз!» на ~3:00 и в финале (комменты работают).
- Факты — по канонической записи сказки (М. Әуезов / «Қазақ ертегілері»); вариации помечать.
## Решения владельца канала
- Длина: 15 минут (~1700–1800 слов при ~115 сл/мин; уточнить по первой озвучке).
- Это СЮЖЕТНЫЙ мультфильм, а не инфографика: захватывающая история, персонажи двигаются и играют сцену (ходьба, бег, жесты, эмоции, погони), камера работает как в кино (общий → средний → крупный).
- Текста на экране минимум: только название, карточки глав (2–3 слова), редкие ключевые надписи. Без плашек-объяснялок, счётчиков и подписей к каждой фразе.
- Формат подачи от «СЕН» — в холодном открытии, на ~3:00 и в финале; основное тело — сама сказка, рассказанная живо, с репликами героев.

## Голоса
- Несколько ИИ-голосов: Рассказчик (Ата-ертегіші), Ертөстік, Жалмауыз кемпір, Ерназар, Кенжекей, Шойынқұлақ и т.д. В сценарии каждая реплика помечена [ГОЛОС].
- Озвучка: владелец генерирует по файлу на реплику (`001_narrator.mp3`, `002_ertostik.mp3`…) или по файлу на голос — склейку и тайминги делаю я; тогда границы реплик точные, паузный метод нужен только внутри длинных реплик рассказчика.

## Уроки
(пополнять после каждого видео)
- (ep01) Темп ИИ-рассказчика ≈122 сл/мин, реплики героев ≈15 симв/с. 1390 слов → 11:55 с паузами. На 15 мин нужно ≈1750 слов.
- (ep01) Озвучку владелец генерирует ОДНИМ mp3 на голос из «чистого» txt (только реплики, пустая строка между ними). Файлы с номерами/именами генератор читает вслух — не давать.
- (ep01) Выравнивание: НЕ анализировать паузы после loudnorm (динамический режим поднимает шум в паузах до −35 дБ). Анализ по исходнику с линейным усилением; порог адаптивный −38→−28 дБ (tools/align.py). Многоточие «...» даёт паузу ВНУТРИ реплики — проверять такие строки, правки в audio/overrides.json.
- (ep01) Инструменты: tools/align_episode.py → tools/build_timeline.py (паузы: тот же голос 0.35с, смена 0.5с, глава 1.2с, немые сцены audio/holds.json) → tools/sync_video.sh (sentences.ts, voice.mp3, env.json для губ) → tools/stills.sh.
- (ep01) Анимация: надписи Big — вне <Camera> (иначе обрезаются зумом). Крупные планы: focus y ≈ 520–560. Позы think/cry/armsUp не должны закрывать лицо (плечи на 0.8 ширины). Закатное солнце не ставить в центр — «нимб» за головой. Табун: позиции через rnd(i), не hash строк (FNV даёт кучки).
- (ep01) Рендер в облаке: 1080p ≈ быстро (10 с видео ≈ 8 с, concurrency 4), браузер /opt/pw-browsers/chromium_headless_shell (см. remotion.config.ts).
- (ep01) Музыка: 4 трека по главам (src/ep01/Soundtrack.tsx), фон 0.30 → под речью 0.09 (огибающая env.json, сглаживание), кроссфейд 24 кадра. Рендер с музыкой ~30 мин в облаке.
- (ep01) Отправка файла владельцу: лимит < 464 МБ. Для загрузки пережимать: x264 crf 23 -tune animation → 180 МБ на 12 мин 1080p.
- (ep01) Превью: Nano Banana + референс-кадр персонажа из Remotion → стиль совпадает. Текст кладём в свободное небо, не на силуэты (src/Thumb.tsx, fitSize 600).
- (ep01) Для правок владельцу: превью 720p с номером сцены (ASS-субтитры) + scenes.md с таймкодами.
- (ep01) Шум толпы (crowd.mp3, исходник −10 дБ) даже на 0.12 глушил голос (фон −19 дБ ≈ речь). Толпу под речь не класть; если нужна — только в немых паузах и ≤0.04. Проверка: RMS в паузах между репликами должен быть ≤ −23 дБ.
- (ep01) Правка только звука: не перерендеривать видео — `remotion render --codec=wav` (~3 мин) + ffmpeg mux с -c:v copy.
