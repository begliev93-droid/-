# Озвучка 1-й серии — как генерировать
1. Каждая строка = отдельный mp3, имя файла указано над строкой (`001_narrator.mp3`). Не обрезай тишину сильно — я подрежу сам.
2. Файлы по голосам: narrator.txt (117 строк), ernazar.txt, ana.txt, tostik.txt, ormekshi.txt, ulken_aga.txt, ortanshy_aga.txt, tabakshy.txt, baibishe.txt. Полный список — lines.tsv.
3. Кидай все mp3 одной папкой/zip.

## Кастинг голосов
| Голос | Характер | Минимум (если голосов мало) |
|---|---|---|
| НАРРАТОР (Ата-ертегіші) | тёплый пожилой мужской, неторопливый, с улыбкой | — |
| ТӨСТІК | молодой мужской, звонкий, решительный | — |
| ЕРНАЗАР | старик, хрипловатый, эмоциональный | — |
| АНА | пожилая женщина, мягкая | — |
| ӨРМЕКШІ КЕМПІР | старуха, резкая, сварливая (комичная) | — |
| ҮЛКЕН АҒА | взрослый мужской, низкий, серьёзный | — |
| ОРТАНШЫ АҒА | взрослый мужской, повыше, комичный | = ТАБАҚШЫ |
| ТАБАҚШЫ | грубоватый мужской, крикливый | = ОРТАНШЫ АҒА |
| БӘЙБІШЕ | женщина средних лет, гостеприимная | = АНА с другой интонацией |
Минимум 6 голосов.

## Темп
Речь ≈12 мин при среднем темпе. Плюс паузы, заставка и немые сцены (дорога, встреча братьев, той) → ~14–15 мин. После первой озвучки подгоню точно: если не хватит — добавлю 1–2 сцены.
